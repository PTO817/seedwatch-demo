# Seedwatch public demo

Uses the private app’s seven-page layout and catalog, manual-entry, comparison, report, and storage screens with synthetic data isolated per visitor. Catalog edits and manual prices update this visitor’s dashboard and history. Live collection and listing tests are simulated; schedule controls do not start background jobs. Amazing Herbs preset prices are at or above MAP. No company database or collector is included.

Deploy all release files together. Streamlit entry point: app.py.
